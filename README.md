# LexTale — Inglês Jurídico & Histórias (PWA Modular v4)

Versão 4 consolidada para publicação no **GitHub Pages** (`advbrasilcampos/lextale`).

## Como apagar as versões antigas no GitHub e deixar só a v4
Você não precisa apagar o repositório nem refazer o GitHub Pages:
1. No GitHub (`advbrasilcampos/lextale`), se houver arquivos extras antigos na raiz ou na pasta `lessons/` que não fazem parte da v4, clique no arquivo antigo $\rightarrow$ menu **`...`** $\rightarrow$ **Delete file** $\rightarrow$ **Commit changes**.
2. Descompacte o `lextale-pwa-v4.zip` no seu computador.
3. No GitHub, clique em **Add file** $\rightarrow$ **Upload files** e arraste todo o conteúdo da pasta descompactada (`index.html`, `style.css`, `app.js`, `manifest.json`, `sw.js`, `icon.svg`, `README.md`, `lessons/` e `assets/`).
4. Clique em **Commit changes**. O GitHub sobrescreve todos os arquivos de mesmo nome e o Service Worker `lextale-pwa-v4` limpa o cache antigo automaticamente após ~1 minuto.
